# Contributing to ExpenseAI

## Getting Started
1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/expense-tracker`
3. Create a branch: `git checkout -b feature/your-feature`
4. Make changes and commit: `git commit -m "feat: your feature"`
5. Push: `git push origin feature/your-feature`
6. Open a Pull Request

## Setup Locally
```bash
# Backend
cd backend
npm install
cp .env.example .env
npm start

# Frontend
cd frontend
npm install
npm run dev
```

## Commit Convention
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `refactor:` code refactor
- `test:` tests

## Code Style
- Use ESLint
- Follow MVC pattern
- Write tests for new features
